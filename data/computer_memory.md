# Computer Memory

## What is RAM?
RAM stands for Random Access Memory. It temporarily stores programs and data that the CPU is currently using. RAM is volatile memory, which means its contents are lost when the power is turned off. More RAM allows a computer to handle more active programs and tasks.

## What is Secondary Storage?
Secondary storage stores data and programs for long-term use. It is non-volatile, meaning data remains stored even when the computer is turned off. Examples include SSDs, HDDs, USB flash drives and memory cards.

## RAM vs Secondary Storage
RAM is temporary working memory, while secondary storage keeps files and programs for long-term use. RAM is generally faster than secondary storage. RAM usually has less capacity and costs more per unit of storage. Secondary storage usually offers greater capacity at a lower cost per unit.

| Feature | RAM | Secondary Storage |
|---|---|---|
| Purpose | Holds currently used data and programs | Stores files and programs long-term |
| Volatility | Volatile | Non-volatile |
| Speed | Generally faster | Generally slower |
| Capacity | Usually smaller | Usually larger |
| Examples | DDR4 and DDR5 RAM | SSD, HDD, USB drive |

## What is Volatile Memory?
Volatile memory requires power to retain its data. RAM is a common example. When power is lost, its stored contents are lost.

## What is Non-Volatile Memory?
Non-volatile memory retains data without continuous power. SSDs, HDDs and USB flash drives are examples of non-volatile storage.

## What is a Page Fault?
A page fault occurs when a program accesses a memory page that is not currently available in physical RAM. The operating system handles the event, often by loading the required page from storage. A page fault does not always mean an error or that another page must be removed.
